# Movie Rating Analysis

## Aim
To analyze movie ratings and review counts using R programming.

## Description
This project contains sample movie names, genres, ratings, and review counts. R is used to calculate the average rating and identify the highest-rated and most-reviewed movies.

## Technologies Used
- R Programming
- Data Frames
- Statistical Functions

## Features
- Displays movie information
- Calculates average rating
- Finds the highest-rated movie
- Finds the most-reviewed movie

## How to Run
1. Open `08_Movie_Rating_Analysis.R`.
2. Run the program in RStudio or VS Code.
3. View the output in the console.

## Result
The program successfully analyzes movie ratings and identifies important movie statistics.
